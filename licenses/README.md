# Dependency license fallback

`github.com/mattn/go-localereader v0.0.1` declares MIT and Yasuhiro Matsumoto as author in its README, but has no standalone license file in that release.

`go-localereader.LICENSE` is the unmodified upstream license from:
https://github.com/mattn/go-localereader/blob/master/LICENSE

The release script includes this text in `THIRD_PARTY_NOTICES.txt`. Other dependency licenses are copied from their versioned Go module directories.
